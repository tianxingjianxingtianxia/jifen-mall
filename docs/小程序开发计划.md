# 小程序开发计划 — 积分商城客户端

> 项目管理规则（血泪教训）：
> 1. **app.json / utils / 类型定义** — 项目经理亲自改，不交给子代理
> 2. **一次只做一个页面**，做完编译验证后再做下一个
> 3. **每个页面任务附完整字段对照表**，子代理禁止靠记忆写字段名
> 4. **WXML 不支持方法调用**，所有数据预计算写 JS
> 5. **每页完成 = 编译通过 + 主流程可走通**，不让甲方当测试员

## 子代理使用规范

1. **只分配给不含工具函数依赖的独立页面**（如积分明细页、个人中心）
2. **每次只分1个页面，做完验证后再分下一个**
3. **附上完整字段名对照表**（从API文档复制），禁止靠记忆
4. **app.json注册路由**—由我统一追加
5. **交付时声明"已对照文档确认字段一致性"**
