# 积分商城系统 (wj_jifen) — 数据库字典

## 概述

- 数据库名: `wj_jifen`
- 字符集: `utf8mb4`
- 排序规则: `utf8mb4_general_ci`
- 引擎: `InnoDB`
- ORM: MyBatis-Plus (MyBatis-Plus)
- 逻辑删除: 使用 `@TableLogic` 标记 `is_deleted` 字段

---

## 公共基类字段 (BaseEntity)

以下字段由 `com.jifen.common.BaseEntity` 定义，被除 `ProductImage` 外的所有实体继承：

| 字段名 | Java类型 | 数据库列 | 类型 | 约束 | 说明 |
|--------|----------|----------|------|------|------|
| id | Long | id | BIGINT | AUTO_INCREMENT PRIMARY KEY | 主键，自增 |
| isDeleted | Integer | is_deleted | TINYINT | DEFAULT 0 | 逻辑删除 (0-未删除, 1-已删除)，`@TableLogic` |
| createTime | LocalDateTime | create_time | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间，`@TableField(fill=INSERT)` |
| updateTime | LocalDateTime | update_time | DATETIME | DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间，`@TableField(fill=INSERT_UPDATE)` |

> **注意**: `ProductImage` 实体不继承 `BaseEntity`，自行定义了 `id` 和 `createTime`，但缺少 `is_deleted` 和 `update_time`。

## Java实体 vs SQL建表语句 差异汇总

| 表 | 差异说明 |
|----|---------|
| **wj_user** | Java实体有 `openid` 字段，但 SQL 建表语句中缺少该列 |
| **wj_point_record** | Java实体有 `expireTime` 字段，但 SQL 建表语句中缺少该列 (`expire_time`) |
| **wj_product_image** | 不继承 BaseEntity，缺少 `is_deleted` 和 `update_time` 字段。Java实体中字段名为 `createTime` (驼峰)，SQL中为 `create_time`，由 MyBatis-Plus 自动映射 |

## 实体继承关系

```
BaseEntity (@TableLogic isDeleted, @TableId AUTO id, createTime, updateTime)
├── User       (@TableName "wj_user")
├── Admin      (@TableName "wj_admin")
├── PointSignIn(@TableName "wj_sign_in")
├── PointRecord(@TableName "wj_point_record")
├── Product    (@TableName "wj_product")
├── Address    (@TableName "wj_address")
├── Order      (@TableName "wj_order")
└── SysConfig  (@TableName "wj_sys_config")

ProductImage  (@TableName "wj_product_image")  ← 独立实体，不继承BaseEntity
```
