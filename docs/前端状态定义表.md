## 1. 订单状态 (Order)

### 状态枚举

| 状态值 | 含义 | 前端显示 | Tag颜色 | 用户端按钮 | 管理端按钮 |
|:---:|------|------|:---:|------|------|
| 0 | 待发货 | 待发货 | warning(橙) | 取消订单 | 发货 |
| 1 | 已发货 | 已发货 | primary(蓝) | 确认收货 | — |
| 2 | 已完成 | 已完成 | success(绿) | — | — |
| 3 | 已取消 | 已取消 | info(灰) | — | — |

### Tab 值映射

| 页面 | 全部 Tab | 待发货 Tab | 已发货 Tab | 已完成 Tab | 已取消 Tab |
|------|:---:|:---:|:---:|:---:|:---:|
| 用户端 `Orders.vue` | `''` | `'0'` | `'1'` | `'2'` | `'3'` |
| 管理端 `admin/Orders.vue` | `'all'` | `'0'` | `'1'` | `'2'` | `'3'` |

### 按钮显示条件

| 按钮 | 页端 | 触发条件 | 说明 |
|------|------|------|------|
| 取消订单 | 用户端 | `order.status === 0` | 创建15分钟内 |
| 确认收货 | 用户端 | `order.status === 1` | |
| 发货 | 管理端 | `row.status === 0` | 填写物流单号 |
| 导出CSV | 管理端 | 始终可见 | 按当前筛选导出 |

### 状态流转

```
0(待发货) ──取消──→ 3(已取消)
    │
    └──发货──→ 1(已发货) ──确认收货──→ 2(已完成)
```

## 4. 积分记录类型 (PointRecord)

| 类型值 | 含义 | 来源标识 |
|:---:|------|------|
| 1 | 获得 | SIGN_IN(签到) / CANCEL(取消退回) / MANUAL_ADJUST(管理员调整) / REGISTER(注册赠送) |
| 2 | 消耗 | EXCHANGE(兑换) |

前端展示时 type=1 显示 `+积分`(绿色)，type=2 显示 `-积分`(红色)

## 6. 接口响应通用结构

所有接口返回值均包裹在以下结构中：

```typescript
interface ApiResponse<T> {
  code: number    // 200=成功
  message: string
  data: T
}
```

### 错误码速查

| code | 含义 | 前端处理 |
|:---:|------|------|
| 200 | 成功 | 正常处理data |
| 400 | 参数错误 | `ElMessage.error(res.message)` |
| 401 | 未登录/token过期 | 跳转登录页 |
| 403 | 无权限 | `ElMessage.error('无权限')` |
| 500 | 服务端错误 | `ElMessage.error(res.message)` |

## 7. 开发和维护规则

1. **前后端状态值必须一致** — 后端用 Integer，前端用 number，不加引号不加转换
2. **新增状态时必须同步更新此文档**，否则按静默失败处理
3. **Tab value 不要混用字符串和数字** — 用户端全部用字符串 `'0'`，传给 API 时转 `Number()`
4. **按钮条件写在 `v-if` 或 `computed` 里**，不依赖 CSS 隐藏
