# 积分商城（微信小程序）— 功能清单

> **项目名称**：积分商城系统（微信小程序版）
> **文档版本**：v1.0
> **编制日期**：2026-05-18
> **编制对象**：甲方验收参考
> **技术栈**：uni-app（前端）/ Spring Boot 3（后端）/ MySQL（数据库）

---

## 一、用户端（小程序）

用户端面向微信授权用户，提供积分获取、商品兑换、订单管理等完整自助服务。

### 1. 微信授权与账户

| 模块 | 功能 | 功能描述 | 入口 |
|:---|:---|---:|:---|
| 授权 | 微信一键登录 | 用户首次打开小程序时，弹出微信授权窗口。用户授权后，系统自动获取微信昵称和头像，后台创建或绑定平台账号（openId），实现免注册、免密码一键登录 | 小程序启动页 |
| 授权 | 微信自动登录 | 已授权用户再次进入小程序时，自动检测微信登录态（wx.checkSession），有效期内自动静默登录，无需重复点击授权 | 小程序启动自动完成 |
| 授权 | 退出登录 | 清除本地登录凭证，返回登录页面 | 个人中心页「退出登录」按钮 |
| 深度绑定 | 微信绑定 | 将微信 openId 与平台账号永久绑定，后续所有操作（签到、兑换、订单）均关联该微信账号。取消授权后可在小程序中重新授权绑定 | 首次授权时自动完成 |

### 2. 积分中心

| 模块 | 功能 | 功能描述 | 入口 |
|:---|:---|---:|:---|
| 积分 | 每日签到 | 用户每天可签到 1 次，签到后获得固定数量积分（默认 10 分，可由管理员配置）。每天 0 点重置签到状态。已签到用户再次点击时提示"今日已签到" | 首页「签到」按钮 |
| 积分 | 积分余额查询 | 查看当前可用积分、累计获得积分、累计消耗积分三项统计数据 | 首页顶部积分卡片 |
| 积分 | 积分明细 | 分页展示积分变动记录，每笔记录包含：变动时间、类型（获得/消耗）、来源（签到/兑换/取消订单）、变动积分数值、备注说明 | 个人中心「积分明细」入口 |

### 3. 商品中心

| 模块 | 功能 | 功能描述 | 入口 |
|:---|:---|---:|:---|
| 商品 | 商品列表 | 以网格卡片形式展示所有上架商品，每件商品显示封面图、名称、所需积分、已兑换数量、库存状态（有货/已售罄）。支持分页加载 | 首页商品网格 |
| 商品 | 搜索商品 | 按商品名称关键词模糊搜索，实时筛选展示匹配的商品 | 首页搜索输入框 |
| 商品 | 排序筛选 | 支持按所需积分升序/降序、按销量从高到低等多种排序方式 | 首页排序下拉框 |
| 商品 | 商品详情 | 查看商品完整信息，包括：商品名称、描述、封面图、轮播图列表、所需积分、当前库存、已兑换数量、商品状态等 | 点击商品卡片进入商品详情页 |

### 4. 地址管理

| 模块 | 功能 | 功能描述 | 入口 |
|:---|:---|---:|:---|
| 地址 | 地址列表 | 展示用户已保存的所有收货地址，每条地址显示收货人姓名、手机号、省市区、详细地址、是否为默认地址 | 个人中心「地址管理」入口 |
| 地址 | 新增地址 | 添加新的收货地址，填写收货人姓名、手机号、省/市/区（三级联动选择器）、详细地址，可选择设为默认地址 | 地址管理页「新增地址」按钮 |
| 地址 | 编辑地址 | 修改已有收货地址的全部信息 | 地址管理页每条地址的「编辑」操作 |
| 地址 | 删除地址 | 删除已保存的收货地址 | 地址管理页每条地址的「删除」操作 |
| 地址 | 设为默认地址 | 将指定地址设为默认收货地址，用于兑换时自动选用 | 地址管理页每条地址的「设为默认」操作 |

### 5. 兑换订单

| 模块 | 功能 | 功能描述 | 入口 |
|:---|:---|---:|:---|
| 订单 | 创建兑换订单 | 在商品详情页选择收货地址后，用积分兑换指定商品。系统即时扣减积分和库存 | 商品详情页「立即兑换」按钮 |
| 订单 | 取消订单 | 订单待发货状态下可主动取消，取消后积分退回、库存恢复 | 订单列表/详情页「取消订单」按钮 |
| 订单 | 确认收货 | 已发货的订单可确认收货，确认后订单状态变为已完成 | 订单列表/详情页「确认收货」按钮 |
| 订单 | 订单列表 | 分页展示用户所有兑换订单，可按订单状态（全部/待发货/已发货/已完成/已取消）筛选查看 | 个人中心「我的订单」入口 |
| 订单 | 订单详情 | 查看订单完整信息，包括：订单号、商品信息、消耗积分数、收货人信息、订单状态及时间线（兑换时间/发货时间/确认收货时间/取消时间）、物流单号 | 点击订单进入订单详情页 |
| 订单 | 物流查询 | 已发货的订单可查询物流运输轨迹，展示物流进度时间线（待接入第三方物流API后可用） | 订单详情页「查看物流」入口 |

## 二、管理端（后台管理系统 — PC Web）

管理端面向运营管理员，提供商品管理、订单处理、数据监控、系统配置等管理功能。**与 Web 版完全一致，共用同一后端服务。**

### 1. 管理员认证

| 模块 | 功能 | 功能描述 | 入口 |
|:---|:---|---:|:---|
| 认证 | 管理员登录 | 管理员通过专用入口使用管理员账号和密码登录后台，登录后持有管理员 Token | `/admin/login` |
| 认证 | 退出登录 | 管理员退出后台管理系统，清除登录状态，返回管理员登录页 | 后台顶部「退出」按钮 |
| 鉴权 | 权限校验 | 所有管理后台接口均需管理员权限，非管理员或普通用户 Token 访问时返回 403 无权限 | 系统自动拦截 |

### 2. 数据看板

| 模块 | 功能 | 功能描述 | 入口 |
|:---|:---|---:|:---|
| 看板 | 关键指标概览 | 展示平台核心运营数据，包括：总用户数、上架商品数、总订单数、待处理订单数 | 后台首页 `/admin/dashboard` |
| 看板 | 积分统计 | 展示累计发放总积分和累计消耗总积分 | 后台首页积分统计卡片 |
| 看板 | 今日签到统计 | 展示今日已签到用户数量 | 后台首页签到统计卡片 |

### 3. 商品管理

| 模块 | 功能 | 功能描述 | 入口 |
|:---|:---|---:|:---|
| 商品 | 商品列表（管理员） | 查看所有商品（含已下架商品），以表格形式展示商品 ID、名称、所需积分、库存、状态（上架/下架）、销量、创建时间等字段。支持按名称搜索和按状态筛选 | `/admin/products` |
| 商品 | 新增商品 | 新增积分兑换商品，填写商品名称、描述、封面图上传、轮播图、所需积分、库存数量、排序权重等信息 | `/admin/products` 页「新增商品」按钮/弹窗 |
| 商品 | 编辑商品 | 修改已有商品的全部信息（名称、描述、图片、积分、库存等） | 商品列表「编辑」操作 |
| 商品 | 上下架商品 | 一键切换商品上架/下架状态。下架后用户在商城端不可见该商品 | 商品列表「上架/下架」按钮 |
| 商品 | 删除商品 | 逻辑删除指定商品，删除后前端不再展示 | 商品列表「删除」操作 |
| 商品 | 导出商品 CSV | 将商品列表数据导出为 CSV 格式文件，方便离线查看和统计 | 商品列表页「导出」按钮 |

### 4. 订单管理

| 模块 | 功能 | 功能描述 | 入口 |
|:---|:---|---:|:---|
| 订单 | 订单列表（管理员） | 查看全平台所有用户的兑换订单，可按订单状态筛选、按订单号搜索。列表展示订单号、用户、商品、消耗积分、收货信息、状态、下单时间等 | `/admin/orders` |
| 订单 | 订单发货 | 对状态为"待发货"的订单进行发货操作，填写物流单号后订单状态变为"已发货"，系统记录发货时间 | 订单列表/详情页「发货」操作 |

### 5. 用户管理

| 模块 | 功能 | 功能描述 | 入口 |
|:---|:---|---:|:---|
| 用户 | 用户列表 | 查看平台所有用户信息，包括用户 ID、用户名、昵称、手机号、积分余额、注册时间等 | `/admin/users` |
| 用户 | 用户详情 | 查看指定用户的详细信息 | 用户列表「详情」操作 |
| 用户 | 调整积分 | 手动增减指定用户的积分，可选择积分来源（转介绍签约/售后回访/手动调整），支持填写备注 | 用户列表「调整积分」操作 |
| 用户 | 导出用户 CSV | 将用户列表数据导出为 CSV 格式文件 | 用户列表页「导出」按钮 |

### 6. 系统配置

| 模块 | 功能 | 功能描述 | 入口 |
|:---|:---|---:|:---|
| 配置 | 查看系统配置 | 查看当前系统配置项及其值：签到奖励积分数 | `/admin/config` |
| 配置 | 修改系统配置 | 修改系统配置项的值（如修改签到奖励积分数），保存后当日签到即按新规则发放 | `/admin/config` 页「保存」操作 |

## 三、业务规则汇总

| 序号 | 规则 | 说明 |
|:---:|:---|:---|
| R1 | 签到规则 | 每天 0 点重置，每人每天只能签到 1 次，奖励积分从系统配置读取（默认 10 分） |
| R2 | 库存预扣 | 用户点击兑换后即时扣减库存，取消订单则恢复库存 |
| R3 | 积分即时扣除 | 兑换时积分即时扣除，不可透支；取消订单时积分即时退回 |
| R4 | 并发控制 | 最后一件商品多人同时兑换，仅 1 人能成功，其余人收到库存不足提示 |
| R5 | 库存为 0 自动下架 | 商品库存变为 0 时，前端页面自动隐藏或禁用兑换入口，提示"已售罄" |

## 六、Web 版 vs 小程序版差异对照

| 差异项 | Web 版 | 小程序版 |
|:---|---:|:---:|
| 登录方式 | 用户名 + 密码 | **微信一键授权登录** |
| 注册方式 | 手动填写注册表单 | 首次授权自动注册 |
| 运行平台 | PC / 手机浏览器 | 微信小程序 |
| 前端框架 | Vue 3 + Vite + Element Plus | uni-app |
| 前后端交互 | HTTP API（axios） | HTTP API（uni.request） |
| 管理后台 | ✅ 完全一致 | ✅ 完全一致（Web 端不变） |
| 后端服务 | ✅ 共用 | ✅ 共用同一后端 |
