# 积分商城系统 — 项目规划方案

## 一、项目概览

| 项目 | 内容 |
|:---|:---|
| 项目名称 | 积分商城系统 |
| 技术栈 | Spring Boot 3 + MyBatis-Plus + MySQL 8 + Redis + Vue3 + Element Plus |
| 数据库 | 独立库 `jifen`，服务器 192.168.1.49 |
| 认证方式 | 独立 JWT 登录系统，本地用户表 |
| 构建工具 | Maven + npm |
| 代码管理 | Git + GitHub (按功能分支提 PR) |
| 方法论 | 分层递进式项目管理 + TDD |
| 开发周期 | 3 个 Sprint，每个 Sprint 约 1 周 |

---

## 六、技术关键点

### 6.1 并发控制（防超卖）
- Redis 分布式锁：兑换时对 product_id 加锁
- 锁超时 10 秒，防止死锁
- 库存扣减使用 MySQL 乐观锁 `UPDATE ... SET stock = stock - 1 WHERE stock > 0 AND id = ?`
- 多人抢最后一件：事务 + 行级锁保证原子性

### 6.2 库存预扣与超时释放
- 创建订单时预扣库存
- Redis 记录订单过期时间（15分钟）
- 定时任务扫描过期订单，释放库存、退回积分
- 使用订单的 expire_time 字段辅助查询

### 6.3 积分过期机制
- 每年 12 月 31 日 23:59:59 执行定时任务
- 统计当年所有获得的积分（签到 + 其他）
- 批量扣减用户积分（不超过当前可用余额）
- 记录积分过期明细

### 6.4 幂等防重复提交
- 重复兑换同一商品 30 天限制：数据库 UNIQUE 或应用层检查
- 前端按钮点击后立即禁用，显示 loading
